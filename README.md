# TaskTracker

## Описание

TaskTracker — учебное консольное приложение на C# для учёта задач. Программа формирует список задач в памяти и выводит его в консоль: идентификатор, название и признак выполнения. Проект используется как демонстрационный пример в практических работах по сопровождению программных проектов: аудиту репозитория, реорганизации структуры и актуализации документации. Графического интерфейса нет: всё взаимодействие происходит через консоль. Текущая версия приложения — 1.3.

## Используемые технологии

- C#;
- .NET 8 (целевая платформа `net8.0`);
- Git и GitHub для контроля версий и публикации проекта;
- JSON — формат файла `data/tasks.json`, подготовленного для хранения задач (в версии 1.3 программа этот файл не загружает);
- Windows batch — вспомогательный скрипт запуска `scripts/run.bat`.

## Требования

- .NET 8 SDK или более новый SDK с поддержкой целевой платформы `net8.0`;
- .NET 8 Runtime для запуска приложения (входит в состав SDK);
- Windows 10 или Windows 11 (именно эта среда использовалась при проверке);
- Git — только для работы с репозиторием, для запуска программы не требуется.

Проверенная среда: Windows, SDK `10.0.401`, среда выполнения `Microsoft.NETCore.App 8.0.31`. Более новый SDK собирает проект `net8.0` без изменений.

## Запуск

1. Установить .NET 8 SDK и проверить установку:

   ```powershell
   dotnet --version
   ```

2. Открыть терминал в корневом каталоге проекта `TaskTracker_AuditProject`.

3. Перейти в каталог, где находится файл проекта:

   ```powershell
   cd src/TaskTracker
   ```

4. Восстановить зависимости:

   ```powershell
   dotnet restore
   ```

5. Собрать проект:

   ```powershell
   dotnet build
   ```

6. Запустить приложение:

   ```powershell
   dotnet run
   ```

Ожидаемый вывод:

```text
TaskTracker 1.3
1: Проверить отчёт | Выполнено: False
2: Обновить документацию | Выполнено: True
```

Дополнительные способы запуска:

- из корня проекта одной командой: `dotnet run --project src/TaskTracker`;
- двойным щелчком по `scripts/run.bat` (скрипт сам переходит в нужный каталог).

## Основные возможности

- вывод названия и версии приложения при старте;
- создание задачи в памяти через метод `TaskService.Add`;
- получение полного списка задач через метод `TaskService.GetAll`;
- вывод задач в формате `Id: Title | Выполнено: True/False`;
- использование модели `TaskItem` с полями `Id`, `Title`, `IsCompleted`;
- определение пути к файлу данных через `FileHelper.GetDataPath`.

Ограничения текущей версии: нет графического интерфейса, нет команд добавления, редактирования и удаления задач, список не сохраняется между запусками.
