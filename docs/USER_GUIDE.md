# Руководство пользователя TaskTracker

Версия приложения: 1.3
Дата обновления: 22.10.2026

## 1. Назначение программы

TaskTracker — учебное консольное приложение на C# для учёта задач. Программа показывает список задач и отмечает, какие из них выполнены. Приложение предназначено для демонстрации работы с моделями, сервисами и структурой проекта в рамках учебной практики, а не для повседневного управления задачами.

## 2. Запуск

1. Установите .NET 8 SDK. Проверьте установку командой `dotnet --version`.
2. Откройте терминал в корневом каталоге проекта `TaskTracker_AuditProject`.
3. Перейдите в каталог с файлом проекта: `cd src/TaskTracker`.
4. При необходимости восстановите зависимости: `dotnet restore`.
5. Соберите приложение: `dotnet build`.
6. Запустите приложение: `dotnet run`.

Из корня проекта можно использовать команду `dotnet run --project src/TaskTracker` или скрипт `scripts/run.bat`.

После запуска в консоли появится версия приложения и список задач:

```text
TaskTracker 1.3
1: Проверить отчёт | Выполнено: False
2: Обновить документацию | Выполнено: True
```

## 3. Основные возможности

- отображение названия и версии программы;
- вывод списка задач с идентификатором, названием и признаком выполнения;
- создание задач в памяти программным способом через `TaskService.Add`;
- получение списка задач через `TaskService.GetAll`;
- работа с моделью задачи `TaskItem` (поля `Id`, `Title`, `IsCompleted`).

## 4. Порядок работы

1. Запустите приложение способом, описанным в разделе 2.
2. Дождитесь вывода строки `TaskTracker 1.3`.
3. Просмотрите список задач. Каждая строка имеет вид `Id: Название | Выполнено: True/False`.
4. Для завершения работы приложение не требует ввода команд: после вывода списка программа закрывается автоматически.
5. Чтобы увидеть изменения списка, измените данные в `Program.cs` и запустите приложение повторно.

В версии 1.3 список задач формируется в коде `Program.cs` и существует только во время выполнения программы.

## 5. Ограничения

- графический интерфейс отсутствует, приложение работает только в консоли;
- нет команд для добавления, редактирования, удаления и отметки задач во время работы;
- список задач не сохраняется между запусками;
- файл `data/tasks.json` и класс `FileHelper` подготовлены для будущего хранения данных, но в версии 1.3 не используются;
- приложение не проверялось на операционных системах, отличных от Windows.
